The Modern Web Interface for
Citrix XenServer & XCP-ng Administration

Replace aging XenCenter with a futuristic, browser-based control plane that unifies pool, host, VM, storage, and network management — with built-in governance, telemetry, and credential security.

🛡

Governance Built-In

Role-based access, destructive-action approvals, pool quotas, and full audit trails. No bolt-ons required.

📊

Live Telemetry

Built-in metrics collector with hourly rollups, capacity forecasting, and noisy-neighbor detection.

🔒

Credential Vault

AES-256-GCM envelope encryption for stored passwords. Key rotation. Zero plaintext exposure.

⚡

No CDN, No Bloat

Single Node.js process. Local SQLite. All vendor assets self-hosted. CSP-safe. Runs anywhere.

Core Capabilities

VM Lifecycle

Start, stop, reboot, suspend, resume, clone, copy, migrate (same-pool & cross-pool), import/export XVA.

Host Operations

Maintenance mode with live VM evacuation, reboot, shutdown, real-time CPU/memory metrics.

Storage & Networking

SR/VDI topology, VIF/PIF mapping, VLAN/bond visibility, network relationship panes.

Alert Center

Telemetry + Xen alerts, acknowledgement, suppression, severity overrides, remediation task creation.

Lifecycle Compliance

Desired-state tracking, drift detection, remediation templates, host maintenance posture.

Resilience & HA/DR

Protection coverage, failover readiness, evacuation targets, recovery runbooks & drills.

Template Governance

Version tracking, golden-image baselines, compare-and-promote workflows, deployment validation.

Activity & Logs

Federated log center: audit, auth, alerts, tasks, telemetry. Export as JSON, HTML, or PDF.

Multi-Target Sessions

Attach to multiple XenServer pools simultaneously. Switch targets without re-authentication.

Inventory Search

Universal search across pools, hosts, VMs, SRs, networks, templates, alerts, and tasks.

Capacity Planning

Memory pressure, storage commitment, top consumers, trend analysis, forecast thresholds.

Remediation Tasks

Alert-to-task workflows, SLA tracking, templates with recurrence guards, audit coverage.
